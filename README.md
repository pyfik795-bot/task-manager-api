# 🌐 Мониторинг доступности сайтов

**Website Connectivity Monitor** — проект на Python для проверки доступности сайтов, измерения времени сетевых операций и получения информации о TLS-соединении.

Программа последовательно проверяет список из 30 доменов, фиксирует результаты проверок и сохраняет подробную информацию в файл `monitor.log`.

## 🚀 Возможности

- **DNS** — проверка разрешения доменного имени в IP-адрес и измерение времени выполнения.
- **TCP** — проверка возможности установить TCP-соединение с сайтом на порту 443.
- **TLS** — установка защищённого соединения и получение информации о TLS.
- **Информация о сертификате** — получение данных о сертификате сервера.
- **HTTP/HTTPS** — отправка GET-запроса и получение HTTP-статуса ответа.
- **Измерение времени** — отдельный замер времени DNS, TCP, TLS, HTTPS и всей проверки сайта.
- **Обработка ошибок** — запись ошибок DNS, TCP, TLS и HTTPS.
- **Логирование** — сохранение результатов проверок в `monitor.log`.
- **Статистика** — подсчёт количества успешных проверок на каждом этапе.

## 🛠️ Используемые технологии

- **Python 3**
- `socket` — работа с сетевыми соединениями и DNS.
- `ssl` — установка TLS-соединений и получение данных о сертификатах.
- `http.client` — отправка HTTPS-запросов.
- `time` — измерение времени выполнения операций.

## 🔍 Как работает программа

Для каждого домена программа выполняет следующие действия:

1. Отправляет HTTPS-запрос и получает HTTP-статус.
2. Разрешает доменное имя в IP-адрес с помощью DNS.
3. Проверяет возможность TCP-подключения к порту 443.
4. Если TCP-подключение успешно, пытается установить TLS-соединение.
5. Получает версию TLS, согласованный набор шифров и сведения о сертификате сервера.
6. Измеряет время выполнения операций.
7. Записывает результаты и ошибки в файл `monitor.log`.

В конце программа выводит статистику успешных проверок DNS, TCP, TLS и HTTPS.

## 📊 Результаты работы

В файле `monitor.log` сохраняются:

- результаты проверок каждого домена;
- HTTP-статусы;
- сведения о TLS и сертификатах;
- время выполнения каждой операции в миллисекундах;
- общее время проверки домена;
- ошибки, возникшие во время проверки;
- итоговое количество успешных проверок.
